# Axial Methodology Website Plan

A single-page website presenting the concept of an Axial Methodology for agentic AI work.  See [the treatise I've written](axial-methodology.md).

The site will include:

- A scrollable single page outlining Axial Methodology
- a brief bio of the author (Joel Helbling)
- a beautiful modern design with a readable theme
  - graphic design elements of inspired by
    - architecture (e.g. grid, dimensions, labels),
    - geometry (e.g. arcs, rotations, cartesian coordinates),
    - CAD and
    - woodworking (e.g. clamps, drill press, planer)
- hosted on GitHub pages
  - custom domain name
